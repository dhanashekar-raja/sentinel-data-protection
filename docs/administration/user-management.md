
# User Management

## Overview

User management enables administrators to manage user accounts within Sentinel Data Protection.

## User Management Tasks

Administrators can perform the following activities:

- Create user accounts.
- Update user information.
- Review account status.
- Disable inactive accounts.
- Remove accounts when access is no longer required.

## User Account Information

| Attribute | Description |
|---|---|
| Username | Unique user identifier |
| Email | User email address |
| Role | Assigned access role |
| Status | Current account status |
| Created Date | Date the account was created |
