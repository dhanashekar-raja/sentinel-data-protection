
# Access Control

## Overview

Access control defines how users access Sentinel Data Protection resources.

## Access Control Principles

The access control model should follow these principles:

- Grant access according to business requirements.
- Apply the principle of least privilege.
- Review permissions periodically.
- Revoke access when it is no longer required.

## Access Levels

| Access Level | Description |
|---|---|
| Administrator | Manages product settings and users |
| Security Analyst | Reviews security activities |
| Standard User | Accesses permitted product features |
