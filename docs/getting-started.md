
# Getting Started

## Overview

This guide introduces Sentinel Data Protection and explains the initial steps required to prepare for installation.

## Before You Begin

Ensure that you have the following:

- Access to the installation package.
- Administrative privileges on the target system.
- Network connectivity to the required services.
- Access to the product configuration details.

## Supported Environments

The following table represents the fictional supported environment for this exercise.

| Component        | Requirement                     |
| ---------------- | ------------------------------- |
| Operating System | Windows Server 2022 or later    |
| Memory           | 8 GB RAM minimum                |
| Storage          | 20 GB available disk space      |
| Network          | HTTPS connectivity              |
| Browser          | Microsoft Edge or Google Chrome |

## Getting Started Workflow

1. Review the system requirements.
2. Download the installation package.
3. Verify the installation prerequisites.
4. Install the application.
5. Configure the initial settings.

!!! important "Important"
    Verify that the target environment meets all prerequisites before beginning installation.
